# polyfont-cli

Command-line interface for polyfont configuration and font management.

## Commands

- `polyfont check` — validate font availability
- `polyfont vscode` — generate VSCode TextMate rules
- `polyfont neovim` — configure Neovim highlights
- `polyfont kitty` — generate Kitty symbol_map entries
- `polyfont dump` — dump resolved font assignments
- `polyfont font list|preview|install` — font management
- `polyfont theme list|import|export` — theme management
